# breath-light

光の広がりと縮みに合わせて、吸う4秒・止める4秒・吐く6秒のリズムで1分間の深呼吸ができるページ。

- 仕様：[docs/spec.md](docs/spec.md)
- 見た目：[docs/design.md](docs/design.md)

[ai-dev-template](https://github.com/Gaku1205/ai-dev-template) の工場で、1行のメモ（1分だけ、光の広がりと縮みに合わせて深呼吸できるページ（吸う4秒・止める4秒・吐く6秒））から作ったサービスです。Issue を書くと、AI が清書・実装・レビュー・マージまで進めます（[docs/pipeline.md](docs/pipeline.md)）。
