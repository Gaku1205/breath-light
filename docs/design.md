# デザイン仕様

breath-light の画面の見た目のルール（色・文字・形・文言・動き）。画面に触る作業では、ここに書かれた物だけを使う。

画面は1つだけ。「始める前」「呼吸中」「終わり」「途中で止まった」の4つの状態を、同じ1画面の中で切りかえる。スクロールして読ませるページではない。

## 1. 使う場面

- **使う人**：推定：仕事や勉強で気持ちが張りつめている大人。スマホに慣れているが、呼吸法やアプリの細かい設定には興味がない。「1分だけなら」と思って開く
- **使う場面**：推定：次の3つ
  - 夜、布団の中で眠れないとき。暗い部屋、スマホ、片手（寝転んで持つ）
  - 会議・発表・試験の直前。廊下やトイレで立ったまま、スマホ、片手
  - 仕事の合間に机で。PC、明るい部屋
  - どれも1回1分。頻度は推定：週に数回、気になったときだけ
- **端末と姿勢**：推定：スマホが主、PC が次。片手。暗い部屋で使うことが多いので、画面が眩しくないことが要る
- **やりたいこと（優先順）**
  1. すぐ始める（開いて1回押すだけ）
  2. 光を見ているだけで、今「吸う・止める・吐く」のどれかと、あと何秒かが分かる
  3. 終わったと分かる。もう1回やりたければ、すぐできる
  - いちばん大事な1つ：**光を見ているだけで、呼吸を合わせられること**
- **見たい情報（優先順）**
  1. 光の大きさ（広がる・止まる・縮む）
  2. 今の段階の言葉（吸う／止める／吐く）
  3. その段階の残り秒数（4・3・2・1）
  4. 全体の残り時間（残り47秒）
  - 最初の1画面に必ず入れる物：光、何をするページか（題と説明1文）、「はじめる」ボタン
- **気持ち**：使う前は「張りつめている・焦っている」。使った後は「少し落ち着いた。1分でできた」。画面は急かさず、静かで、何も考えずに従えること
- **失敗すると困ること**
  - 段階の取り違え（止めるところで吸ってしまう）。光の動きと言葉と秒数が、少しでもずれると従えない
  - 眩しさ（暗い部屋で白い画面が一気に光る）
  - 途中で画面がスリープして止まる。推定：スマホの自動ロックが30秒の人がいる。画面を消さない（Screen Wake Lock API。依存パッケージは要らない）かは、仕様書で決めてほしい
  - 情報が多くて目が光から離れる

## 2. サービスの型と優先順位

**型：鑑賞・作品・体験**（主）。1分間、光を見て体で感じる物で、記録も比較もしない。

- 最優先：光そのものの気持ちよさ（なめらかさ、大きさ、色）と、従いやすさ。光の動きと言葉と秒数が、ぴったり合っていること
- 抑える物：説明の文、数字、ボタンの数、光のほかに動く物。呼吸中の画面に出す物は「光・段階の言葉・秒数・残り時間・やめる」の5つだけ

**参考にした仕組み**（ブランドの色・書体・文句は使っていない）

- Tesla（`references/brands/tesla.md`）：1画面に1つの主役だけを置き、UI はそれを邪魔しないように引っ込める。唯一の色をいちばん大事な操作にだけ使う。→ 主役は光。光の色を「はじめる」ボタンにだけ使う
- Oura（`references/brands/oura.md`）：太さではなく大きさの差で階層をつける。詰めずに長い間をとる。→ 段階の言葉は大きいが細め（400）。周りは広く空ける
- Spotify（`references/brands/spotify.md`）：再生中の画面では、中身（ジャケット）が色を持ち、操作はその下にまとめて置く。→ 色を持つのは光だけ。操作は画面の下、親指の届く所にまとめる

**taste-skill で選んだ方向**：`colour-chapters`（Colour chapters、seed 1463426138、sector health）。配られた3つは `borrowed-category`（別の分野の装い）、`editorial-report`（印刷の報告書）、`colour-chapters`（章ごとの平らな色の面）。

- 選んだ理由：「場面ごとに、画面全体を1色の平らな面にする」考え方が、「始める前・呼吸中」と「終わり」で地の色を変えるのに合う。報告書の型は読み物向け、別分野の装いは落ち着きと逆向きなので選ばなかった
- この画面の考え：**breath-light の「4・4・6」のリズムが、画面いっぱいの1つの光の大きさになる**。生きた物（触って変わる物）は、この光そのもの
- 使った所：平らな地の面（グラデーション無し）、章で地の色を変えること、一つの書体系、強調色は操作に1か所だけ
- 変えた所と理由
  - 配られた色（明るいパステル5色）→ 使わない。暗い部屋で使う場面が多く、明るい地は眩しい。夜の深い青を地にして、光の色を淡い灯りの色にした
  - 書体 Chivo（900・大文字）→ 日本語が読めないので、日本語は Zen Kaku Gothic New にした。Chivo は欧文の名前と数字だけに使う（400）
  - 写真のモザイクの頭、写真の束、アコーディオン、タイルのフッター → 使わない。1画面で光だけを見る物なので、写真や部品は目を光から離す
  - 見出しが下からせり上がる演出（Masked headline）→ 使わない。動いてよいのは光だけ（「8. 動き」）

## 3. 構図

光・段階の言葉・下の操作を、画面の縦の中心線に揃えて置く（中央揃え）。目を光から横に動かさずに済むように。光の位置は、どの状態でも動かない（状態を切りかえても光が跳ねない）。全部が中央揃えなのは、円が1つだけの、中心から広がる構図だから（読み物の画面ではないので、左揃えの文の塊が無い）。

### 寸法

- 外の余白（左右）：スマホ 20px、PC（1024px 以上）48px。どちらも `env(safe-area-inset-*)` を足す
- 光の箱の一辺 `--stage`：`min(84vw, 44svh, 520px)`
  - 390×844：327px／360×640：282px／1440×900：396px／2560×1440：520px
- 縦の並び（上から）
  1. 上の帯：高さ 56px。左に名前「breath-light」（始める前だけ。ほかの状態では空ける）
  2. 光の箱：上下に 16px ずつ空けて、`--stage` の正方形を左右中央に置く
  3. 段階の欄：高さ 112px（中身は状態で変わる。高さは変えない）
  4. 説明の欄：始める前・終わり・途中で止まった、のときだけ
  5. 下の操作の帯：画面の下に付ける（`margin-top: auto`）。下の余白はスマホ 24px、PC 48px（＋safe-area）
- 背の低い画面（`@media (max-height: 700px)`。360×640 など）：上の帯を 40px、`--stage` を `min(84vw, 36svh, 520px)`、段階の欄を 96px にする（S5 の 44px＋8px＋S3 で収まる）。「はじめる」を最初の1画面に入れるため
- ページは `min-height: 100svh`。中身が入りきらない（横向きのスマホ、文字の拡大）ときは、普通に縦にスクロールしてよい。`overflow: hidden` で切らない

### 光の形

- 器（うつわ）：直径 `--stage` の円。色 `--vessel`。光が最大まで広がったときの大きさを、前もって見せる
- 光：直径 `--stage` の円を、`transform: scale()` で大きさを変える。最小 `0.3`、最大 `1`。色 `--light`。縁はくっきり（ぼかし・光彩・影をつけない）
- 器と光は同じ中心

### スマホ（390×844）

### PC（1024〜2560px）

- 並べ方はスマホと同じ縦1列の中央揃え。横に並べ替えない（光が主役で、横に置く物が無い）
- 説明の文は最大幅 28em。ボタンは幅 280px、中央
- 2560×1440 では光が 520px で止まり、周りに地が広く残る。これは意図した「間」で、物を足して埋めない

### 終わり・途中で止まった

始める前と同じ並び。段階の欄に見出し、説明の欄に1文、下の操作の帯にボタン2つ（上が「もう1分はじめる」、その下に「最初の画面へ」。間 8px）。PC では2つを横に並べる（左が「もう1分はじめる」、間 16px）。

## 4. 色

地は夜の深い青。色を持つのは光（淡い灯りの色）だけで、同じ色を主なボタンにも使う。「終わり」の章だけ、地を少し明るい青に変える（夜が少し明けたように）。

| 名前 | 値 | 用途 |
| --- | --- | --- |
| `--bg` | `#1B2236` | 地（始める前・呼吸中・途中で止まった） |
| `--bg-done` | `#33456B` | 地（終わり） |
| `--vessel` | `#252F4A` | 器の円（地から一段だけ明るい） |
| `--light` | `#F3E3B8` | 光。主なボタンの地。フォーカスの線 |
| `--light-hover` | `#FAEFD2` | 主なボタンに乗せたとき |
| `--light-press` | `#E3D09E` | 主なボタンを押したとき |
| `--text` | `#ECEEF3` | 題・段階の言葉・本文 |
| `--text-sub` | `#AEB6C9` | 秒数・残り時間・名前・文字だけのボタン |
| `--on-light` | `#1B2236` | 主なボタンの文字（`--bg` と同じ値） |

コントラスト比（WCAG の式で計算）

| 文字（前） | 地（後） | 比 | 使う所 |
| --- | --- | --- | --- |
| `--text` | `--bg` | 13.6:1 | 本文・段階の言葉 |
| `--text-sub` | `--bg` | 7.8:1 | 秒数・残り時間・やめる |
| `--text` | `--bg-done` | 8.2:1 | 終わりの見出し・本文 |
| `--text-sub` | `--bg-done` | 4.7:1 | 終わりの「最初の画面へ」 |
| `--on-light` | `--light` | 12.4:1 | 主なボタンの文字 |
| `--on-light` | `--light-hover` | 13.8:1 | 同（乗せたとき） |
| `--on-light` | `--light-press` | 10.4:1 | 同（押したとき） |
| `--light`（線） | `--bg` | 12.4:1 | フォーカスの線 |
| `--light`（線） | `--bg-done` | 7.5:1 | 同（終わり） |
| `--light`（光） | `--vessel` | 10.4:1 | 光と器の境 |
| `--vessel` | `--bg` | 1.2:1 | 器と地の境（飾りの段差。意味は言葉と秒数が運ぶので、これだけに頼らない） |

- 色だけで意味を伝えない。段階は必ず言葉（吸う／止める／吐く）と秒数で出す。光の色は段階で変えない
- `<html>` に `color-scheme: dark`。`<meta name="theme-color">` は `#1B2236`（終わりの章でも変えない）
- グラデーション・半透明の重ね・影は使わない。面は平らな1色

## 5. 文字

| 役 | 書体 | 太さ | 用途 |
| --- | --- | --- | --- |
| 日本語 | Zen Kaku Gothic New（Google Fonts） | 400・700 | 題・段階の言葉・本文・ボタン |
| 欧文と数字 | Chivo（Google Fonts） | 400 | 名前「breath-light」、秒数、残り時間の数字 |

- 選んだ理由：Zen Kaku Gothic New は、細めでも暗い地で字がつぶれず、「吸う」「吐く」のような画数の違う字が並んでも同じ明るさに見える。丸ゴシックは癒やし系の決まりの見た目になりやすいので避けた。Chivo は配られた方向の書体で、数字の形が素直で読みやすい
- 数字は `font-variant-numeric: tabular-nums`。残り時間の数字は `min-width: 2ch` で幅を固定し、減っても横に揺れないようにする
- `font-display: swap`。`word-break: auto-phrase`。11.5px より小さい文字は使わない

大きさの段（5段）

| 段 | 大きさ | 行の高さ | 字間 | 使う所 |
| --- | --- | --- | --- | --- |
| S1 | 14px | 1.5 | 0.02em | 名前「breath-light」、残り時間 |
| S2 | 16px | 1.8 | 0.02em | 説明の文、ボタン（700） |
| S3 | 20px | 1.4 | 0 | 段階の残り秒数（Chivo）、終わりの見出しの下の文はS2 |
| S4 | `clamp(28px, 1.5vw + 22px, 36px)` | 1.35 | 0.04em | 題「1分の深呼吸」、終わりの見出し（どちらも 400） |
| S5 | `clamp(44px, 3vw + 32px, 64px)` | 1.1 | 0.12em | 段階の言葉（吸う・止める・吐く）、400 |

- 段階の言葉は太くしない（400）。大きさで目立たせ、急かす感じを出さない
- 揃えはすべて中央。説明の文は最大 28em、`text-wrap: pretty`。見出し（題・終わりの見出し・途中で止まった見出し）は `text-wrap: balance`（狭い画面で2行に折れても片寄らない）

## 6. 部品と状態

### 光と器

- 押せない（`button` にしない、`aria-hidden="true"`）。乗せても押しても何も変わらない
- 見え方は「8. 動き」

### 段階の欄（呼吸中）

- 段階の言葉（S5、`--text`）と、その下 8px に残り秒数（S3、Chivo、`--text-sub`）
- 段階の欄の箱ごと `aria-live="polite"`。読み上げは段階が変わったとき（「吸う」「止める」「吐く」）と、終わり・途中で止まったの見出しが出たときだけ。残り秒数・残り時間は `aria-hidden="true"`（毎秒読み上げない）

### 見出しの組み立て

- 題「1分の深呼吸」（h1）は、どの状態でも DOM に残す。始める前は見せ、ほかの状態では見えなくする（画面からは隠し、読み上げには残す `sr-only` の形）。終わり・途中で止まったの見出しは h2（h1 の下に来る）

### 主なボタン（はじめる・もう1分はじめる）

| 状態 | 見え方 |
| --- | --- |
| 通常 | 地 `--light`、文字 `--on-light` S2 700、高さ 56px、角は丸（高さの半分＝28px）。幅：スマホは左右の余白いっぱい、PC は 280px |
| 乗せた | 地 `--light-hover`（150ms） |
| 押した | 地 `--light-press`、`scale(0.98)`（80ms） |
| フォーカス | `:focus-visible` で `outline: 2px solid var(--light)`、`outline-offset: 4px` |
| 使えない | 作らない（押せないときはボタンを出さない） |
| エラー | 無い（押すと必ず始まる） |

角を丸にするのは光の円とそろえるため。このページの角の丸みはこれ1種類だけ。

「乗せた」の見え方は、2種類のボタンとも `@media (hover: hover)` の中だけで付ける（スマホで押したあとに乗せた色が残らないように）。

### 文字だけのボタン（やめる・最初の画面へ）

| 状態 | 見え方 |
| --- | --- |
| 通常 | 地なし、文字 `--text-sub` S2 400、押せる範囲は 44px 以上×横 `padding: 0 16px` |
| 乗せた | 文字 `--text`、下線 1px（`text-underline-offset: 4px`） |
| 押した | 文字 `--text`、`opacity: 0.7` |
| フォーカス | 主なボタンと同じ線 |
| 使えない・エラー | 無い |

- 両方とも `<button>`（画面を切りかえるだけで、別の URL へは行かない）
- キーボード：呼吸中は Esc でも「やめる」と同じ動き
- フォーカスの移り方：「はじめる」「もう1分はじめる」を押したら「やめる」へ。終わり・途中で止まったら（「やめる」を押したときも）「もう1分はじめる」へ。「最初の画面へ」なら「はじめる」へ。読み込み時に自動でフォーカスしない
- 消えている物（今の状態で見せない文字やボタン、消える途中の物も）は、DOM から外すか `inert` にする。見えないボタンに Tab で止まらないように
- `touch-action: manipulation`。`-webkit-tap-highlight-color: transparent`（押した見え方は上の表で出す）

## 7. 空・読み込み中・エラー

- **空（最初に開いたとき）**＝「始める前」の画面。光は最小（0.3）で止まっている。題・説明・「はじめる」だけで、何をすればいいか分かる
- **読み込み中**：専用の画面は作らない。サーバーで「始める前」を描いておく。書体が届く前は端末の書体で出る（`font-display: swap`）
- **途中で止まった**：「やめる」（または Esc）を押したときと、呼吸中にタブを切りかえる・画面がスリープするなどで、ページが隠れたとき（`visibilitychange`）。ページが隠れたときは、時間がずれて光と合わなくなるので、案内を止め、この画面を出す。見出し・説明・ボタンは「9. 文言」（説明はどちらで止まったかで変える）。地は `--bg` のまま、光は最小に戻す
- **JavaScript が動かない**：`<noscript>` で説明の欄に「9. 文言」の文を出し、「はじめる」は出さない

## 8. 動き

このページで勝手に動いてよいのは、光だけ。ほかの物は、押した反応と状態の切りかえ以外で動かさない。GSAP・Lenis は使わない（大きさを変える1つの円と、文字の差し替えだけなので、CSS と `requestAnimationFrame` で足りる）。

### 呼吸の時間

「はじめる」を押した瞬間から、吸う4秒・止める4秒・吐く6秒（1回14秒）をくり返し、60秒で終わる（4回と、5回目の吸う4秒）。数え方は仕様書（`docs/spec.md`「1分の数え方」）。

| 段階 | 長さ | 光の大きさ | 曲線 |
| --- | --- | --- | --- |
| 吸う | 4秒 | 0.3 → 1 | `cubic-bezier(0.37, 0, 0.63, 1)`（なめらかに始まり、なめらかに止まる） |
| 止める | 4秒 | 1 のまま | — |
| 吐く | 6秒 | 1 → 0.3 | `cubic-bezier(0.37, 0, 0.63, 1)` |

- 光は `transform: scale()` だけで変える（大きさ・幅・高さを動かさない）。`transform-origin: center`
- 時計は1つ（`performance.now()` からの経過時間）。光の大きさ・段階の言葉・残り秒数・残り時間を、すべてこの1つの時計から決め、互いにずれないようにする
- 段階の言葉は、段階が始まる瞬間に切りかえる。古い言葉は段階が終わる 200ms 前から 200ms で消し、新しい言葉は境目の瞬間から 200ms で出す（`opacity` だけ、`ease`。位置は動かさない）。こうすると、新しい言葉が出始めるのと光の動きが変わるのが同じ瞬間になる。読み上げ用の言葉（`aria-live`）は境目の瞬間に差し替える
- 残り秒数は、段階の残りを切り上げた整数（4→3→2→1）。数字は動かさずに差し替える
- 残り時間は、全体 60秒から経過を引いて切り上げた整数（はじめた瞬間が「残り60秒」、最後の1秒が「残り1秒」）

### 状態の切りかえ

- 「はじめる」を押す：題・説明・ボタン・名前が 300ms で消え（`opacity`、`cubic-bezier(0.22, 1, 0.36, 1)`）、段階の欄に「吸う」と「4」が 300ms で出る。光は押した瞬間から広がり始める（位置は動かない）
- 終わり：60秒で最後の「吸う」が終わったら、光を 1 から 0.3 へ 400ms（`cubic-bezier(0.22, 1, 0.36, 1)`）で戻す。同時に地を `--bg-done` に変える。地の色そのものを動かさず、`--bg-done` の全面の層を `opacity` 0→1 に 1200ms（`ease`）。そのあと見出し・説明・ボタンが 300ms で出る
- 「やめる」：光を今の大きさから 0.3 へ 400ms（`cubic-bezier(0.22, 1, 0.36, 1)`）で戻し、同時に途中で止まったの見出し・説明・ボタンを 300ms で出す
- 押した反応：ボタンは 80ms 以内に見え方が変わる（「6. 部品と状態」）
- `transition: all` は使わない。動かす物を名指しする

### `prefers-reduced-motion: reduce` のとき

光の大きさは呼吸の案内そのものなので、消さずに、なめらかな動きをやめて段にする。

- 光は1秒ごとに段で大きさが変わる。各1秒の始まりの瞬間に、その1秒の終わりの大きさへ跳ぶ（吸う：1〜4秒目の始まりに 0.475 → 0.65 → 0.825 → 1、吐く：1〜6秒目の始まりに 0.883 → 0.767 → 0.65 → 0.533 → 0.417 → 0.3）。段階が変わった瞬間に光も変わるので、言葉とずれない。段のあいだは動かさない（`transition` なし）
- 言葉の切りかえ・状態の切りかえ・終わりの地の変化は、すべて一瞬で差し替える
- ボタンの `scale(0.98)` はしない（色の変化だけ）

## 10. 避けること

このサービスで起きやすい失敗

- 光の動きと言葉と秒数のずれ（別々のタイマーで動かす、`setInterval` を積み重ねる）。必ず1つの時計から決める
- 光に光彩・ぼかし・放射状のグラデーション・影をつける（「光らしく」したくなるが、AIが作った感の典型で、暗い部屋では眩しい）。縁のくっきりした平らな円にする
- 段階ごとに地や光の色を変える（4〜6秒ごとに画面全体の色が変わると落ち着かない。色だけで段階を伝えることにもなる）
- 呼吸中に情報を足す（回数のグラフ、心拍、記録、励ましの文、進み具合の棒）。目が光から離れる
- 3つの段階に 01／02／03 や「ステップ1」の番号をつける（くり返す輪なので、順番の番号は合わない。文で書く）
- 光をタップで操作させる・スワイプで止める（押し間違いの元。操作はボタンだけ）
- 音や振動を勝手に出す
- 白い地・明るいパステルの地（暗い部屋で眩しい）
- 名前の上の小さな大文字のラベル、ピル型のバッジ、等幅の書体の小さな文字、細い区切り線、カードの箱
- 黒に近い地に蛍光の強調色を1つ、という決まりの見た目（地は深い青、光は淡い灯りの色）
- クリーム色の地にテラコッタ、紫・藍の強調
- 見出しの1語だけ色や斜体を変える
- 癒やし系の決まり文句（「マインドフルネス」「今ここに」など）と絵文字、葉っぱや波の飾り
- 拡大の禁止（`user-scalable=no`・`maximum-scale=1`）、`overflow: hidden` でのはみ出しの切り捨て
