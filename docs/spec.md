# 仕様書

アプリの「何を・どう動かすか」を書く。AIは作業の前に必ずここを読む。

## 目的

光の広がりと縮みに合わせて、吸う4秒・止める4秒・吐く6秒のリズムで1分間の深呼吸ができるページ。（元のメモ：1分だけ、光の広がりと縮みに合わせて深呼吸できるページ（吸う4秒・止める4秒・吐く6秒））

## 前提

- 使う人・使う場面（デザイン部門の分析。推定を含む）：
  - 使う人（推定）：仕事や勉強で気持ちが張りつめている大人。スマホに慣れているが、呼吸法や細かい設定には興味がなく、「1分だけなら」と思って開く
  - 使う場面（推定）：夜に布団の中で眠れないとき（暗い部屋・スマホ・片手）、会議や試験の直前（立ったまま・スマホ・片手）、仕事の合間に机で（PC）。1回1分、週に数回、気になったときだけ
  - 開いて1回押すだけで始められ、呼吸中は光を見ているだけで「吸う・止める・吐く」とあと何秒かが分かることが、いちばん大事
- 技術：Next.js（App Router）＋TypeScript、テストはVitest

## 画面

画面は `/` の1つだけ。見た目・文言・動きの細かい所は `docs/design.md`。ここには挙動を書く。

### 状態と切りかえ

同じ1画面の中で、次の4つの状態を切りかえる。URL は変えない。

| 状態 | 出す物 | できること |
| --- | --- | --- |
| 始める前（最初に開いたとき） | 名前、光（最小 0.3 で止まる）、題「1分の深呼吸」、説明1文、「はじめる」 | 「はじめる」→ 呼吸中 |
| 呼吸中 | 光・段階の言葉・段階の残り秒数・残り時間・「やめる」の5つだけ | 「やめる」または Esc → 途中で止まった。60秒たつ → 終わり。ページが隠れる → 途中で止まった |
| 終わり | 光（0.3）、見出し、説明1文、「もう1分はじめる」「最初の画面へ」。地は `--bg-done` | 「もう1分はじめる」→ 呼吸中（0秒から）。「最初の画面へ」→ 始める前 |
| 途中で止まった | 光（0.3）、見出し、説明1文、「もう1分はじめる」「最初の画面へ」。地は `--bg` | 終わりと同じ |

- 「途中で止まった」になるのは2つ：「やめる」（または Esc）を押したとき、と呼吸中にページが隠れたとき（`visibilitychange` で `document.visibilityState` が `hidden`。タブの切りかえ・画面のスリープなど）。説明の文は、どちらで止まったかで変える（文言は design.md「9. 文言」）
- 「もう1分はじめる」は、いつも0秒から数え直す（続きからは再開しない）
- 状態を切りかえても光の位置は動かない

### 1分の数え方

- 「はじめる」（または「もう1分はじめる」）を押した瞬間を0秒とし、すぐ「吸う」から始める。準備の段階（「用意」）は置かない
- 吸う4秒 → 止める4秒 → 吐く6秒（1周14秒）をくり返し、60秒で終わる。60秒＝4周（56秒）＋5周目の吸う4秒。最後の周回は「吸う」が終わったところで切れる（止める・吐くは無い）
- 段階の境目は、その瞬間から次の段階とする（例：4秒ちょうどは「止める」、14秒ちょうどは2周目の「吸う」）
- 60秒に達した瞬間に「終わり」にする。終わったら光は 0.3 に戻す（design.md「8. 動き」）
- 経過時間は時計1つで決める。「はじめる」を押したときの `performance.now()` を覚え、毎フレーム（`requestAnimationFrame`）その差を経過時間にする。光の大きさ・段階・残り秒数・残り時間・終わったかを、すべてこの経過時間から1つの関数（`src/lib/breath.ts`）で出す。`setInterval` で数えを積み重ねない（フレームが間引かれても数えがずれない）

### 秒数の出し方

- 段階の残り秒数：その段階の残り時間を切り上げた整数。吸う 4・3・2・1、止める 4・3・2・1、吐く 6・5・4・3・2・1
- 全体の残り時間：60秒から経過を引いて切り上げた整数。はじめた瞬間が「残り60秒」、最後の1秒が「残り1秒」
- 光の大きさ：吸うは 0.3 → 1、止めるは 1 のまま、吐くは 1 → 0.3。吸う・吐くの途中は曲線 `cubic-bezier(0.37, 0, 0.63, 1)` で補う。始める前・終わり・途中で止まったは 0.3

### 画面を消さない

- 呼吸中だけ Screen Wake Lock API（`navigator.wakeLock.request("screen")`）で画面を消さないようにする。依存パッケージは使わない
- 終わり・途中で止まった（やめる・ページが隠れた）になったら解除する
- 対応していないブラウザ、または要求が失敗したときは、何も出さずに呼吸の案内をそのまま続ける

### 動きを減らす設定

- `prefers-reduced-motion: reduce` のときは、光を消さずに1秒ごとの段で大きさを変える。各1秒の始まりに、その1秒の終わりの大きさへ跳ぶ（design.md「8. 動き」）
- 言葉と状態の切りかえ・終わりの地の変化は、一瞬で差し替える

### キーボードと読み上げ

- 操作はすべてボタン（`<button>`）で、Tab と Enter／Space で使える。呼吸中は Esc でも「やめる」と同じ
- フォーカスの移り方：「はじめる」「もう1分はじめる」を押したら「やめる」へ。終わり・途中で止まったら「もう1分はじめる」へ。「最初の画面へ」なら「はじめる」へ。読み込み時は自動でフォーカスしない
- 読み上げは段階が変わったときと、終わり・途中で止まったの見出しが出たときだけ。秒数は毎秒読み上げない
