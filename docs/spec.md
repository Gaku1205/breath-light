# 仕様書

アプリの「何を・どう動かすか」を書く。AIは作業の前に必ずここを読む。

## 目的

光の広がりと縮みに合わせて、吸う4秒・止める4秒・吐く6秒のリズムで1分間の深呼吸ができるページ。（元のメモ：1分だけ、光の広がりと縮みに合わせて深呼吸できるページ（吸う4秒・止める4秒・吐く6秒））

## 前提

- 使う人・使う場面（デザイン部門の分析。推定を含む）：
  - 使う人（推定）：仕事や勉強で気持ちが張りつめている大人。スマホに慣れているが、呼吸法や細かい設定には興味がなく、「1分だけなら」と思って開く
  - 使う場面（推定）：夜に布団の中で眠れないとき（暗い部屋・スマホ・片手）、会議や試験の直前（立ったまま・スマホ・片手）、仕事の合間に机で（PC）。1回1分、週に数回、気になったときだけ
  - 開いて1回押すだけで始められ、呼吸中は光を見ているだけで「吸う・止める・吐く」とあと何秒かが分かることが、いちばん大事
- 技術：Next.js（App Router）＋TypeScript、テストはVitest
